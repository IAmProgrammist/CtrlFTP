# Example client

A simple FTP client created for testing purposes. Run `setup.sh` to prepare application for running. 
This script will download all required dependencies, compile .qrc file and .ui files. 

You can specify python directory before running `setup.sh` by setting environmanet variable `PYTHON_DIR`. Variable
`PYTHON_DIR` defaults to `.venv`.

After setup you will be able to run application from `main.py`.
